# THE CONQUEROR

하늘에서 떨어진 지 사십 일, 이름도 기억도 잃은 기사가 눈을 뜬다.

## 다운로드

**[TheConqueror.exe 받기 (Windows)](https://github.com/abrace1322/the-conqueror/releases/latest/download/TheConqueror.exe)**

항상 최신 버전이 받아집니다. 설치 없이 받은 파일을 더블클릭하면 바로 실행됩니다.

## 처음 실행할 때

- 브라우저가 "흔히 다운로드되는 파일이 아닙니다"라고 경고하면 **유지** 또는 **계속**을 누르세요.
- "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
- 실행할 때마다 화면이 뜨기까지 몇 초 걸릴 수 있습니다.

## 저장

진행은 자동으로 저장되고, 껐다 켜면 타이틀의 **기록 이어가기**로 이어집니다. 새 버전 exe로 바꿔도 기록은 그대로 남습니다.
